S20 Mail Watch

계정 소유자가 본인의 휴대전화에서 실행하는 개인용 메일 확인 도구입니다. 하루 한 번 연결한 받은편지함을 읽고, 보안 경고·업무 요청·기한 등 정해진 규칙에 해당하는 메일을 본인이 지정한 Discord 채널로 알려줍니다. 일반 사용자를 모집하거나 가입을 받지 않습니다.

개인정보처리방침

이 도구는 계정 소유자가 승인한 Gmail 읽기 전용 권한으로 메일의 식별자, 수신 시각, 발신자, 제목, 본문 및 라벨을 읽습니다. 연결한 다른 메일 서비스에서도 받은편지함을 읽어 같은 목적으로 처리합니다. 메일 발송, 삭제, 보관, 라벨 변경은 하지 않습니다.

본문은 중요도 규칙을 적용하는 동안 휴대전화 메모리에서 처리합니다. 본문 원문과 첨부파일을 파일로 보관하거나 Discord에 보내지 않습니다. 생성형 AI 서비스에 본문을 전송하지 않습니다.

중요 메일에 한해 계정 주소, 발신자, 제목, 분류 이유, 메일함 링크를 계정 소유자가 지정한 Discord 채널에 전송합니다. 이 정보는 Discord에 저장되며 채널 접근 권한이 있는 사람이 볼 수 있습니다. Discord의 보관 및 삭제 정책이 별도로 적용됩니다.

인증 토큰은 휴대전화의 접근 권한이 제한된 설정 파일에 저장합니다. 중복 알림 방지를 위한 메일 식별자의 해시, 확인·발송 시각, Discord 메시지 식별자와 실행 결과를 휴대전화에 보관합니다. 메일 내용은 광고, 판매, 프로파일링 또는 AI 모델 학습에 사용하지 않습니다.

계정 소유자는 Google 계정의 연결된 앱 설정에서 접근 권한을 취소하고 휴대전화의 예약 작업, 인증 설정 및 처리 기록을 삭제하여 사용을 중단할 수 있습니다. Discord에 이미 전달된 알림은 해당 채널에서 별도로 삭제할 수 있습니다. 인증 설정과 처리 기록은 소유자가 삭제할 때까지 보관됩니다.

S20 Mail Watch의 Google API 정보 사용 및 다른 앱으로의 전달은 제한된 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

이용 안내

본인 소유 메일함의 개인적인 확인 보조 용도로 사용합니다. 중요도는 규칙으로 판단하므로 중요한 메일을 놓치거나 불필요한 메일을 알릴 수 있습니다. 기한·보안·결제 등 중요한 사항은 원본 메일함에서 직접 확인해야 합니다. 별도 이용료는 없으며 메일 서비스와 Discord의 이용 조건이 적용됩니다.
